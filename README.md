# Caesar Cipher

A simple Python-based **Caesar Cipher encryption and decryption tool**.

This project allows the user to enter plain text and a shift value, then:

* Encrypt the text using the Caesar Cipher algorithm.
* Decrypt the encrypted text back to the original message.
* Preserve spaces, numbers, and special characters.
* Handle both uppercase and lowercase letters.

## Features

* 🔐 Text Encryption
* 🔓 Text Decryption
* 🔤 Supports uppercase and lowercase letters
* 🔢 Preserves numbers and special characters
* 🐍 Built with Python
* 💻 Simple command-line interface

## How It Works

The Caesar Cipher is a substitution cipher where each letter in the message is shifted by a fixed number of positions in the alphabet.

For example, with a shift of `3`:

HELLO → KHOOR
Decryption reverses the same process:
KHOOR → HELLO
